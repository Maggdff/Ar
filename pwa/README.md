# نسخة PWA للآيفون
- `shared/core.js`: النواة (أكواد، PBKDF2/AES-GCM/HMAC، ECDSA بتوقيع DER، صندوق الطالب، بروتوكول QR) متوافقة مع أندرويد. اختبار: `node tests/core.test.js`.
- `student/`: تطبيق الطالب (تفعيل ← جدول ← بياناتي ← تسجيل بالـQR).
- **المتبقي:** تطبيق الدكتور `doctor/` (ربط QR، مزامنة الكشف، توليد التحدّي ومسح الإجابات، كشف، رفع الحضور).
- النشر: ارفع مجلد `pwa/` كما هو على GitHub Pages (HTTPS شرط للكاميرا)، ثم في Safari: مشاركة ← «إضافة إلى الشاشة الرئيسية».
- لا بلوتوث في Safari على iOS، لذا التسجيل عبر QR فقط.
