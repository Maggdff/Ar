# مهارات العربية — تطبيق مذاكرة (Kotlin + Jetpack Compose)

تطبيق أندرويد عربي RTL يعمل دون إنترنت، مبني على «موجز في بعض مهارات اللغة العربية».

## المزايا
- دروس: القاعدة، الشروط، الأمثلة، الخلاصة، الأخطاء الشائعة، حالة التحقق، والنص الأصلي المستخرج.
- رسوم تفاعلية داخل الدروس لتسهيل الحفظ: شرائح اختيار، بطاقات اختبار ذاتي (اضغط لإظهار الجواب)، شجرات قرار بنعم/لا، وشريط زمني. بياناتها في `assets/diagrams.json` (يولّدها `tools/build_diagrams.py`).
- اختبارات (صح/خطأ، اختيار من متعدد) بتصحيح فوري وشرح: لدرس، لوحدة، للكتاب كاملًا، أو للأخطاء المحفوظة.
- حفظ الأخطاء وإعادة اختبارها (الخطأ يُزال عند الإجابة الصحيحة لاحقًا).
- بطاقات مراجعة (نظام صناديق لايتنر) لكل الأسئلة بما فيها التطبيقي والدقيق.
- حفظ التقدم محليًا مع زر «مسح التقدم» في الشاشة الرئيسية.
- «Developed by Maggd Alosimi» أعلى الشاشة الرئيسية.
- حفظ محلي (SharedPreferences) — لا إنترنت ولا حسابات.

## البناء
- الأسهل: ارفع المجلد إلى مستودع GitHub؛ سيعمل `Build Android APK` ويُنتج artifact باسم `ArabicSkills-debug-apk` من تبويب Actions.
- محليًا: JDK 17 + Android SDK 35 ثم `./gradlew assembleDebug` والناتج في `app/build/outputs/apk/debug/`.
- اختبار المنطق دون Android SDK: `tools/local_test.sh` (يحتاج Gradle مثبّتًا لمكتباته).

## البنية
- `model/`, `logic/`, `data/ContentParser|ProgressCodec`: Kotlin نقي وله اختبارات JUnit.
- `ui/`: شاشات Compose. `assets/`: بيانات الكتاب (مولَّدة بـ `tools/build_data.py`).
- `tools/make_icon.py`: يولّد الأيقونة بكل الأحجام.
- انظر `DATA_AUDIT.md` لتوثيق البيانات والتعديلات.

## التصميم
هوية «حبر ومداد»: حبر نيلي على ورق رمادي بارد، وأحمر للأخطاء الشائعة، وتظليل أصفر للتحديد. العناوين بخط النسخ والمتن بالخط الافتراضي. الأقسام نص مسطّح بخط رأسي ملوّن، والصناديق للعناصر التفاعلية فقط. الألوان والأشكال في `ui/Theme.kt`، ويولّد `tools/make_icon.py` الأيقونة بنفس الألوان.
